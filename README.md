# My Reimplementation
After studying the original learning material, I decided to reimplement the neural network myself from scratch.
For this reimplementation, I did NOT follow the tutorial step by step.
I tried to write it independently and only referred back to the tutorial when I got stuck or needed to review a concept.
The purpose of this project is to test my understanding of neural networks and improve my Python programming skills.
